  # <Color id="dark_purple">Wizard's Reborn</Color>

  <ItemImage id="arcane_wand" scale="2" />

  Wizard's Reborn is a magic mod built around Wissen — a mystical energy refined from Arcanum ore. Harvest arcane resources, build crystalline infrastructure, brew alchemical reagents, and ultimately cast powerful spells using elemental crystals.
</Column>

<Column alignItems="center" fullWidth={true}>
  ## <Color id="gold">Progression Overview</Color>
</Column>

<ItemImage id="minecraft:air" scale="0.5"/>

1. Mine <ItemLink id="arcanum" /> and grind it into <ItemLink id="arcanum_dust" />
2. Create <ItemLink id="arcane_wood_sapling" /> and <ItemLink id="raw_arcane_gold" /> using Arcanum Dust
3. Build a <ItemLink id="wissen_altar" /> to generate Wissen energy
4. Craft an <ItemLink id="arcane_workbench" /> and <ItemLink id="wissen_crystallizer" />
5. Grow elemental Crystal Seeds and harvest Crystals
6. Set up Alchemy with the <ItemLink id="alchemy_machine" />
7. Produce advanced materials like Calx and <ItemLink id="arcacite" />
8. Build the <ItemLink id="arcane_iterator" /> and perform Rituals
