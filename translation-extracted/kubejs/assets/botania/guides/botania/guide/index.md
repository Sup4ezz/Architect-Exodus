  # <Color id="green">Botania</Color>

  <ItemImage id="lexicon" scale="2" />

  Botania — магико-технологический мод о природе, в котором вся энергия поступает от <Color id="green">Mana</Color>, производимой магическими цветами. Создавайте цветы в Petal Apothecary, получайте Mana с помощью Generating Flora, используйте её для питания Functional Flora и автоматизации, создавайте руны на Runic Altar и позднее открывайте портал в Alfheim ради продвинутых рецептов. Несмотря на цветочную эстетику, в основе Botania лежат технологии: почти всё можно автоматизировать с помощью редстоуна и смекалки.
