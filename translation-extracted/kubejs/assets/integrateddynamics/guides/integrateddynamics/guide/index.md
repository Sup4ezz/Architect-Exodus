  # <Color id="aqua">Integrated Dynamics</Color>

  <ItemImage id="logic_programmer" scale="2" />

  Integrated Dynamics is the go-to mod for automating your logic systems. It provides an expressive, immersive logic programming experience with hooks and support for most elements of Minecraft and its modifications. Build networks, define variables, and create complex automation logic without writing a single line of code.
</Column>

<ItemImage id="minecraft:air" scale="0.25"/>

<Column alignItems="center" fullWidth={true}>
  ## <Color id="gold">Progression Overview</Color>
</Column>

<ItemImage id="minecraft:air" scale="0.5"/>

1. Find Menril Trees and craft a <ItemLink id="squeezer" /> and <ItemLink id="drying_basin" /> to process Menril resources
2. Build a network with <ItemLink id="cable" /> (Logic Cable) to connect your machines and storage
3. Craft <ItemLink id="variable" /> (Variable Cards) and readers to extract information from the world
4. Use a <ItemLink id="logic_programmer" /> to create logic programs that process and combine variables
5. Store variables in a <ItemLink id="variablestore" /> (Variable Store) for reuse across your network
6. Build advanced machines like <ItemLink id="materializer" /> and <ItemLink id="proxy" /> for powerful automation
