# Dye Liquifier

<BlockImage id="dye_liquifier" scale="5"/>

<ItemImage id="dye_liquifier" scale="0.5"/> Dye Liquifier превращает красители в жидкость <ItemImage id="pure_dye_fluid_bucket" scale="0.5"/> Pure Dye Fluid.

Разные красители дают разное количество жидкого цвета. Сейчас каждый цвет даёт <WootConfig key="dye_liquifier.color_produce_amount" /> мБ; при этом сразу производится <WootConfig key="dye_liquifier.pure_dye_produce_amount" /> мБ <ItemImage id="pure_dye_fluid_bucket" scale="0.5"/> Pure Dye Fluid.

Можно загружать как готовые красители, так и ингредиенты для их создания — например, цветы.

<Recipe id="dye_liquifier/white" />

Показанный рецепт иллюстрирует принцип работы. Точное количество жидкости для каждого предмета смотрите в JEI (Just Enough Items).
