# <Color id="light_purple">Enhancement</Color>

<Column alignItems="center" fullWidth={true}>
  # <Color id="light_purple">Enhancement</Color>
<ItemImage id="minecraft:amethyst_block" scale="2" />

An imperfect ritual that marks an enchanted item as Blood Enhanced, boosting all enchantment levels by +1. The enhancement is applied dynamically — the item's actual enchantment data is never modified, only how it is read.

</Column>

<ItemImage id="minecraft:air" scale="0.25"/>

***

### <Color id="aqua">Details</Color>

* <Color id="gold">Activation Block:</Color> Amethyst Block 
* <Color id="red">LP Cost:</Color> 5000
* <Color id="green">Effect:</Color> Marks the held item as **Blood Enhanced** — all enchantments display and function at +1 level above their base

## <Color id="aqua">Limitations</Color>


* Items can only be enhanced **once**
* The item must already have at least one enchantment
* Use the [Reduction](reduction.md) ritual to remove the Blood Enhanced mark

<ItemImage id="minecraft:air" scale="0.25"/>

### <Color id="aqua">Usage</Color>

1. Place an **Amethyst Block** on top of the Imperfect Ritual Stone
2. Hold an **enchanted item** in your mainhand
3. Right-click the Imperfect Ritual Stone
4. The item is marked Blood Enhanced — the stone remains for reuse
