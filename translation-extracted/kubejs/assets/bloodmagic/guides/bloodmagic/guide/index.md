# <Color id="red">Blood Magic</Color>

<Column alignItems="center" fullWidth={true}>
  # <Color id="red">Blood Magic</Color>

  <ItemImage id="bloodmagic:altar" scale="2" />

  Blood Magic — мод о магии крови, основанной на использовании <Color id="red">очков жизни (LP)</Color>, получаемых при жертвоприношении здоровья. LP позволяют создавать мощные предметы, питать ритуалы и создавать Living Armor, которая становится сильнее по мере использования.
</Column>

<ItemImage id="minecraft:air" scale="0.25" />

***

<Column alignItems="center" fullWidth={true}>
  ## <Color id="gold">Основные этапы развития</Color>
</Column>

<ItemImage id="minecraft:air" scale="0.5"/>

1. Создайте <ItemLink id="bloodmagic:altar" /> и изготовьте <ItemLink id="bloodmagic:sacrificialdagger" />.
2. Создайте <ItemLink id="bloodmagic:blankslate" />, чтобы открыть доступ к новым рецептам.
3. Создайте <ItemLink id="bloodmagic:weakbloodorb" />, чтобы сформировать свою Soul Network.
4. Улучшайте уровни алтаря с помощью <ItemLink id="bloodmagic:blankrune" />.
5. Изучите алхимию, Demon Will и Sigils.
6. Настройте ритуалы для получения мощных эффектов по области.
7. Создайте <ItemLink id="bloodmagic:livingplate" />, броню, которая совершенствуется сама.
