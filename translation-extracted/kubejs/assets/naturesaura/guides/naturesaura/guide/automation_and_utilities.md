<Column alignItems="center" fullWidth={true}>
  ## <Color id="gold">Imperceptible Builder</Color>
</Column>

<ItemImage id="minecraft:air" scale="0.25"/>

<Row>
  <ItemImage id="placer" />
  ### <Color id="aqua">Imperceptible Builder</Color>
</Row>

The Imperceptible Builder automatically places blocks in its area. Place an Item Frame on its side to specify which blocks it should place on top of. It draws items from an inventory placed on top of it, and uses a small amount of local aura.

This is especially useful for automating the placement of <ItemLink id="gold_powder" /> rings for the Ritual of the Forest.

<Column alignItems="center" fullWidth={true}>
  ## <Color id="gold">Autonomous Activator (Auto Crafter)</Color>
</Column>

<ItemImage id="minecraft:air" scale="0.25"/>

<Row>
  <ItemImage id="auto_crafter" />
  ### <Color id="aqua">Auto Crafter</Color>
</Row>

The Auto Crafter is a multiblock structure that automates crafting table recipes using aura. It requires a frame built from Ancient Planks and Ancient Logs.

Materials needed:
- 1x <Color id="green">Auto Crafter</Color>
- 40x <Color id="green">Ancient Planks</Color>
- 8x <Color id="green">Ancient Log</Color>
