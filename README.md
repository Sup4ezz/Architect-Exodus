# Architect Exodus — русификация сборки Minecraft 1.20.1

Репозиторий для перевода модов сборки **Sborka** на русский язык. Рабочая ветка: `translation-source`.

**Цель:** подготовить полноценный русификатор, который можно установить в Minecraft как ресурс-пак. Изменения должны сохраняться непосредственно в этом репозитории через коммиты GitHub.

## Как продолжать работу в новом чате

Не нужно заново объяснять проект. Отправь ссылку на репозиторий:

https://github.com/Sup4ezz/Architect-Exodus/tree/translation-source

И напиши: **«Продолжай русификацию по чек-листу в README. Проверь актуальное состояние ветки и сразу делай массовые переводы в GitHub. Не ограничивайся отчётами».**

Перед работой помощник должен:
1. Прочитать этот README и проверить текущую ветку `translation-source`.
2. Посмотреть последние коммиты и актуальные `en_us.json` / `ru_ru.json`, чтобы не переводить повторно уже готовое.
3. Выбрать следующий крупный неполностью переведённый мод или раздел и внести реальные изменения в файлы.
4. Сначала переводить большие объёмы текста в квестах и книгах; не тратить время на массовое переименование предметов. Сверять названия предметов с игровыми именами и держать их единообразными.
5. Проверить JSON, сохранить плейсхолдеры (`%s`, `%1$d`, `%%` и подобные), форматирование Minecraft (`§`), ключи и управляющие символы.
6. Записать изменения коммитом в `translation-source`, затем обновить чек-лист в README, если статус действительно изменился.
7. В конце кратко сообщить, что реально изменено, дать ссылки на коммиты и указать следующий приоритет. Не объявлять русификатор готовым, пока он не собран и не проверен.

## Чек-лист проекта

### Источники и структура
- [x] Создана рабочая ветка `translation-source`.
- [x] В репозитории собраны извлечённые языковые файлы модов и ресурсы перевода.
- [x] Есть скрипт для сбора языковых ресурсов установленной сборки.
- [ ] Сверить состав модов и версий с фактически установленной сборкой.
- [ ] Убедиться, что в итоговый ресурс-пак попадут только файлы, нужные игре, а не архивы исходников и вспомогательные материалы.

### Перевод
- [ ] Проверить все пары `en_us.json` / `ru_ru.json` и определить реальную долю переведённых строк, а не оценивать прогресс по числу коммитов или размеру файлов.
- [ ] Приоритет №1 — полностью перевести квесты FTB Quests: названия, описания, главы, предупреждения, награды, подсказки и тексты переходов.
- [ ] Приоритет №2 — полностью перевести внутриигровые книги и руководства, включая Patchouli, GuideME, KubeJS Markdown и встроенные страницы.
- [ ] Перевести описания, подсказки, сообщения и интерфейс, но не тратить основное время на перевод обычных названий предметов.
- [ ] Сохранять названия предметов и модов на английском, если пользователь не просил иначе; любые упоминания предметов в книгах и квестах должны совпадать с реальным отображаемым названием в игре.
- [ ] Проверить ресурсы KubeJS и пользовательские тексты сборки.
- [ ] Единая терминология обязательна: английское название предмета в инвентаре должно точно совпадать с названием, которым этот предмет называют в книге или квесте. Не должно быть ситуаций, когда в тексте написано «Кровавый камень», а сам предмет называется «Blood Stone» (или наоборот). По умолчанию сохранять игровые названия предметов на английском, если нет согласованного перевода для всего проекта.
- [ ] Не переводить вслепую идентификаторы, команды, технические значения и имена авторов.
- [ ] Не заменять неизвестный текст выдуманным переводом. Для неоднозначных терминов выбирать перевод по игровому контексту.
- [ ] Не копировать английские значения в русский файл только ради заполнения ключей; при необходимости оставлять оригинал осознанно и отмечать его как непереведённый.

### Техническая проверка
- [ ] Проверить корректность JSON всех изменённых файлов.
- [ ] Сравнить ключи английского и русского файлов: найти отсутствующие ключи и английские строки, оставшиеся без перевода.
- [ ] Проверить плейсхолдеры, последовательности форматирования, переносы строк и специальные символы.
- [ ] Проверить, что структура итогового ресурс-пака соответствует Minecraft 1.20.1 и игре не требуется исходная папка `translation-extracted`.
- [ ] Собрать единый устанавливаемый ZIP ресурс-пака.
- [ ] Установить пак в Minecraft 1.20.1 и проверить загрузку, меню, предметы, описания, книги и квесты.
- [ ] Исправить ошибки, найденные в игре, и пересобрать ZIP.

### Выдача результата

## Сбор языковых ресурсов из установленной сборки

1. Открой [Collect-Translation-Resources.ps1](./Collect-Translation-Resources.ps1).
2. Нажми **Raw** и сохрани файл на рабочий стол как `Collect-Translation-Resources.ps1`.
3. Открой PowerShell и выполни:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
& "$env:USERPROFILE\Desktop\Collect-Translation-Resources.ps1"
```

Скрипт рассчитан на экземпляр сборки по пути `%APPDATA%\.minecraft\versions\Sborka`. Он создаёт `Sborka-Translation-Source.zip` на рабочем столе. Скрипт собирает текстовые языковые ресурсы и не должен менять саму сборку или папку `saves`.

Этот архив — **источник для работы, а не готовый русификатор**. Часть текстов может храниться в форматах, которые скрипт не извлекает.
